# SEO Content Strategy

## Intent match

- For each target query, check the live SERP: what page types actually rank (guides, product pages, comparison tables, tools)? If your page's type differs from the top results, that's an intent mismatch — restructure the page type, don't just rewrite copy.
- The primary answer must appear in the first screen of content, not after 800 words of preamble.

## Cannibalization detection

- In GSC Performance, filter to one query and open the Pages tab: one query splitting clicks across multiple URLs with alternating positions = cannibalization.
- Cross-check with `site:domain.com intitle:"keyword"` to list every competing page.
- Fix by consolidating (301 the weaker page and merge its unique content) or by differentiating intent so each page targets a distinct query set. Never leave two pages targeting the same query "to see which wins".

## Topic cluster template

- One pillar page + 5-10 spoke pages per cluster.
- Spokes link to the pillar AND to sibling spokes, with descriptive anchor text (the target topic, never "read more" / "click here"). The pillar links down to every spoke.
- Each page has exactly one distinct role and query set within the cluster; if two spokes answer the same question, merge them.

## E-E-A-T checks

- Claims are backed by first-party data, experience, or a cited credible source — flag unsourced statistics.
- Named authors with real bio pages and credentials; no "Admin" bylines on expertise content.
- Visible last-updated dates that reflect real content changes, not cosmetic date bumps.

## Refresh priority

- Refresh first the pages where impressions are rising but CTR or position is falling: demand exists and the page is losing the selection battle. Pull this from GSC by comparing periods per page; it beats refreshing by age.
- For each refresh: re-check current SERP intent, update facts, add what top-ranking pages cover that you don't.

## Metadata systems

- Define title/description templates per page type (pattern + unique variable), one unique H1 per page, and answer-first summaries under headings so snippets and AI answers can extract them.
